# 句译 · 中译英翻译写作练习工具
**JuYi-ZH-EN-Sentence-Practice**

---

句译是一个专为英语学习者设计的单页应用。

通过“单句拆分，专注输出”，只需粘贴一段中文原文，程序会自动将其拆分为单句，以逐句进行英文翻译练习。

遇到生词随时调用内置词典，最终将写好的句子一键复制交给 AI 进行批改优化。

## 快速开始
- 下载 .html 文件，双击打开即可运行
- 输入中文段落，拆句，翻译
- 将逐句翻译结果或整篇翻译结果复制，交由 AI 进行批改优化。

## 核心功能
- 智能分句：自动按标点符号将中文原文拆分为单句列表。
- 专注写作：逐句翻译，逐句校对
- 划词查词：在中文原句中选中生词，自动弹出浮标，点击即可查阅英文译法。
- 错误标红：在写好的英文译文中，选中特定词组或语法错误进行“标红”，方便日后复盘。
- 版本管理：支持保存“初稿”与“终稿”，随时查看历史版本、只读预览或一键恢复。
- 数据备份：一键导出全量 JSON 备份文件，支持随时导入恢复。
- 数据完全本地存储。

## 说明
  - 使用查词典功能时，可能调用有道词典、MyMemory 机器翻译、Free Dictionary API提供查词服务。
